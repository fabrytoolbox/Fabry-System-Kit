# 🟢 Fabry-System-Kit (Matrix Edition)

> *"Io non ho paura. Io sono l'utente amministratore."*

Benvenuto nel **System Kit**. Qui non si scherza con i multimedia: qui si mette mano al sistema operativo, alla rete, alle configurazioni e ai processi. 
Una cassetta degli attrezzi pesante, per chi vuole il controllo totale su Windows, sempre con l'inconfondibile interfaccia Matrix.

## 🧰 Gli Strumenti

### 🖥️ Sistema & Manutenzione
*   **[App-Uninstaller-Tool](https://github.com/fabrytoolbox/App-Uninstaller-Tool)** — Disinstallatore robusto con Ghost Hunter, Deep Scan, GUI Matrix e CLI. Quando "Pannello di Controllo" non basta più.
*   **[System-Sentinel-Matrix](https://github.com/fabrytoolbox/System-Sentinel-Matrix)** — Task Manager Matrix con protezione processi critici. Tieni d'occhio chi osa consumare la tua RAM.
*   **[Norton-NIS-RAM-Monitor](https://github.com/fabrytoolbox/Norton-NIS-RAM-Monitor)** — Monitora il consumo di RAM dei processi di Norton Internet Security. Perché l'antivirus non deve rallentarti.
*   **[IsoMounter-Matrix](https://github.com/fabrytoolbox/IsoMounter-Matrix)** — Monta e smonta ISO con GUI Matrix, log e pulizia automatica. Addio utility di terze parti.
*   **[Subst-Manager](https://github.com/fabrytoolbox/Subst-Manager)** — GUI per gestione comando Subst con persistenza all'avvio. Mappa le tue cartelle come un pro.

### 🌐 Rete & Sicurezza
*   **[MATRIX_HOSTS](https://github.com/fabrytoolbox/MATRIX_HOSTS)** — Gestione file hosts con GUI Matrix, validazione e backup. Blocca la pubblicità o reindirizza il traffico con stile.
*   **[NetAdapter-Manager](https://github.com/fabrytoolbox/NetAdapter-Manager)** — Gestione avanzata schede di rete (IP, DNS, DHCP, SubNet Mask, Gateway). Il coltellino svizzero del sysadmin.
